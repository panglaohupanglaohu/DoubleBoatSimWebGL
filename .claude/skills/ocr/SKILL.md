# OCR 截图识别 Skill

从 UI 截图、设计稿、页面截图中提取中英文文本，直接用于前端开发。

## 核心方法

使用 `view_image` 工具读取图片，利用多模态模型能力直接识别图中文字。**零依赖**，无需安装任何 OCR 引擎。

## 适用场景

| 场景 | 说明 |
|------|------|
| UI 截图 → 代码 | 从截图中提取按钮文字、标签、菜单项，直接写入 HTML/i18n |
| 设计稿文案提取 | 从 Figma/Sketch 导出图中批量提取中英文文案 |
| 截图对比 | 对比截图中的实际文字与代码中的预期文字 |
| 数据表格提取 | 从仪表盘截图中提取数值、单位、指标名 |
| 多语言校对 | 识别截图中的中/英文，检查翻译是否正确 |

## 工作流程

### 单张图片识别

1. 用户提供图片路径（本地文件或粘贴到聊天）
2. 使用 `view_image` 工具读取图片
3. 逐区域识别文本，按 **空间布局** 输出（从上到下、从左到右）
4. 输出格式化的文本结果

### 批量识别

1. 用 `file_search` 找到目标图片（`**/*.{png,jpg,jpeg,webp,gif}`）
2. 逐张调用 `view_image`
3. 汇总所有提取文本

### 截图 → i18n 词条

1. 识别截图中的所有中文文本
2. 检查 `js/i18n.js` 的 `TEXT_MAP` 中是否已有对应翻译
3. 输出缺失的词条列表，格式：`['中文', 'English'],`
4. 可直接追加到 `TEXT_MAP`

### 截图 → HTML 代码

1. 识别截图中的文字内容和大致布局
2. 生成对应的 HTML 结构，文字内容直接填入
3. 保持截图中的层级关系（标题、正文、标签、按钮等）

## 输出规范

### 纯文本提取

按空间位置输出，用缩进表示层级：

```
[顶部导航栏]
  PoseidonX    导航态势    能效合规    安全应急

[主内容区 - 左侧面板]
  船舶状态
    航速: 12.4 节
    航向: 045°
    
[主内容区 - 右侧面板]  
  天气预报
    风速: 18 节
    浪高: 2.1 米
```

### i18n 词条格式

```javascript
// 从截图提取的缺失翻译词条
['导航态势', 'Navigation Situation'],
['能效合规', 'Energy Compliance'],
['安全应急', 'Safety Emergency'],
```

### 结构化 JSON（用于数据提取）

```json
{
  "region": "dashboard-panel",
  "items": [
    { "label": "航速", "value": "12.4", "unit": "节" },
    { "label": "航向", "value": "045", "unit": "°" }
  ]
}
```

## 识别技巧

1. **分区识别**：大图先描述整体布局，再逐区域提取文字
2. **中英混排**：同时识别中文和英文/数字，保持原始混排格式
3. **图表数据**：对柱状图/折线图，提取坐标轴标签和数据点
4. **小字/水印**：明确告知用户小字可能识别不准确
5. **图标+文字**：分别标注图标描述和旁边的文字

## 限制

- 依赖 `view_image` 工具可用性
- 手写体、极小字号（<8px）、严重模糊图片识别率较低
- 不支持 PDF 文件（需先转为图片）
- 复杂表格的单元格对齐可能需要人工校正
